# Ex02 - If/else

Para este exercício if/else, a minha ideia foi tentar reproduzir uma luz forte que vai surgindo aos poucos, ou de forma repentina, através do movimento do mouse da esquerda para a direita, ou então o desaparecimento dessa luz através do movimento do mouse da direita para a esquerda. Para isso,recorri a um degradê monocromático.
Inicialmente usei o Gemini para pesquisar como é que eu poderia dividir a minha tela em 3 partes diferentes e atribuir a cada uma dessas partes uma cor diferente através das condicionais if/else. Após entender e fazer o teste, fui adicionando mais divisões (ao todo foram 15) e as diferentes cores de background, para conseguir fazer um degradê que desse a impressão de que uma luz está a ser ligada ou a aproximar-se, ou o oposto disso.
